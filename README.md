# KV Caching LLM Inference Cost Reduction

This Python script demonstrates the concept of KV Caching for Large Language Models (LLMs). It simulates an LLM's inference process and uses a simple dictionary to cache results based on prompt and token count, significantly reducing computation time for repeated or similar requests.

## Language

`python`

## How to Run

Run this script using a Python interpreter: `python kv_caching_llm.py`
